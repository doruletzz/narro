# Narro Frontend

Astro + Tailwind CSS + Keystatic CMS

## Development

```bash
cd frontend
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Project Structure

- `src/pages/` — Astro pages
- `src/components/` — UI components (ui/, layouts/, sections/)
- `src/content/schemas/` — Keystatic content schemas
- `keystatic.config.ts` — Keystatic CMS configuration
